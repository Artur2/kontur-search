
#  kontur-search

---
Port of my interview-based project Kontur.Search

* **Implementation of Trie Algorithm:** The project implements a trie data structure for efficient word search.
* **Priority Support for Passed Words:** It supports prioritizing the search results based on the priority of the passed words.
* **Extremely Fast Performance:** The implementation is optimized using Rust programming language, resulting in blazing-fast search performance.
* **Command-Line Interface (CLI) Support:** The project provides a comprehensive CLI interface for easy user interaction.


---
Querying a single word in a 1 million-word text performed by a 10-us to 1-ms.
